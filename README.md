# JW Legacy Enterprises — Official Website Source

Professional, responsive standalone business website for **JW Legacy Enterprises**, founded by **Jermaine Williams (Main’O)**.

## Website

The business is **developing** its offerings. The site describes focus areas and example projects without implying services or hours not yet confirmed.

- Home: `index.html`
- About: `about.html`
- Services: `services.html`
- Projects: `projects.html`
- Contact: `contact.html`
- Shared presentation: `styles.css`
- Mobile navigation and contact-copy helper: `script.js`
- Brand monogram icon: `favicon.svg`

## Contact

Business inquiries: **jwlegacyenterprises@gmail.com**. Contact is by direct email; this website does not host a database or collect form submissions.

## Deployment

Designed for static hosting (for example Vercel connected to this GitHub repository). There is no package installation, build step, API key, or server runtime.

Connect the repository to the hosting provider and use `main` as the production branch. Keep the business website and the personal Bludit website in separate hosting projects.

The business does not have its own custom domain yet. When ready, add a separate business domain without altering the personal site's domain.

## Updating

Edit and commit the files in this repository. Test navigation, responsive layouts, internal links, and email links before publishing. This repository is public, so never commit credentials or private records.
